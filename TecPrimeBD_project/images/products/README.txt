This folder is reserved for LOCAL product images.

Right now index.html loads product photos directly from the web
(Unsplash links), so this folder is empty.

If you ever want to use your own photos instead:
1. Save each image here, e.g. images/products/headphones.jpg
2. In index.html, change the <img src="..."> for that product
   from the Unsplash link to: images/products/headphones.jpg
